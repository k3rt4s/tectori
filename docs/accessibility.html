Accessibility

The site should work for everyone who visits it.

Effective date: September 9, 2025

The target

Tectori's target for this website is Web Content Accessibility Guidelines (WCAG) 2.1 level AA. The site is reviewed against that target as content changes.

What the site does today

Pages use semantic HTML with landmarks, headings, and labeled navigation. Every page starts with a skip to content link. Images carry text alternatives. Form fields on the login preview have visible labels. Navigation, including the mobile menu, works with a keyboard. Text and background colors are chosen for contrast and readability.

Known limits

The site is reviewed with automated checks and manual testing rather than a formal external audit. Some issues may not be caught before a visitor finds them.

Report an issue

If any part of this site is hard to use with assistive technology, tell Tectori directly at contact@tectori.com. Reports go straight to the founder and are treated as defects, not feedback for a backlog.
