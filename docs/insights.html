AI email security vs. traditional defenses: Why both matter

AI email security complements traditional defenses by detecting sophisticated threats through behavior analysis and context understanding.

AI email security is evolving to counter sophisticated threats like BEC and spear phishing. Traditional tools are effective at blocking spam and known malware but struggle with attacks that exploit trust and human behavior. These threats often come from legitimate accounts, use familiar patterns, and lack obvious technical indicators. AI steps in by analyzing behavior, language, and context to detect anomalies that traditional systems miss.

AI creates user profiles and flags deviations, like emails sent outside normal hours or from unfamiliar IPs. It also uses NLP to identify pressure tactics and pretexting attempts. Context analysis helps detect impersonation by comparing sender-receiver relationships against historical communication patterns. This layered approach is critical as attackers use AI to craft convincing, personalized messages at scale.

Combining traditional methods with AI provides a robust defense. SPF, DKIM, and DMARC still play a vital role in verifying sender authenticity, while AI adds depth by understanding intent and communication context. This hybrid model is essential for identifying threats that bypass conventional detection, especially in high-stakes scenarios like fraudulent payment requests.

CISOs should audit their email security architecture and integrate AI where it adds value. Ensuring AI systems align with existing tools like SIEM and SOAR reduces alert isolation and improves response times. Governance around data processing is also key, especially when handling sensitive information. The future of email security lies in balancing tradition with innovation.

AI Coding Agents Are Getting Malicious Results From Web Search Indexes, WebSec Benchmark Finds

AI coding agents are vulnerable to malicious content in web search results which can lead to malware installation without human intervention.

AI coding agents act on whatever web search hands them, and no person checks first. In AIR's tests, all eight search APIs handed them known-malicious content. A coding agent hits an error it doesn't know how to fix, so it searches the web. Unlike a developer, it doesn't stop to judge the results. It acts on the top hits: it installs the package a forum post recommends, or runs the command a README suggests.

The risks are real. A malicious page built to rank first can trick an agent into installing malware. The attack path is simple: a developer asks for a Solana project setup, the agent searches, picks the first result, runs the command, and the machine is compromised. Nobody clicked anything, and no person read the README before the agent acted on it. The repository, known as SolanaCry, and its payload are real. The researchers recovered the payload from the Web Archive after its download link went dead and tied it to known NetSupport Manager campaigns.

This isn't just about bad actors. Hijackable websites in top search results are a growing problem. An attacker doesn't always have to build a page that ranks. Sometimes the page already ranks and the domain behind it is up for sale. A site's place in a search index can outlive the site itself. The WebSec Benchmark shows how often this happens. Every one of the eight search APIs served known-malicious content at least once. The rate ran from 0.8% to 2.2%, one bad search in every 45 to 125.

Security teams must treat everything an agent reads as untrusted input. Check search results, READMEs, and install commands before they reach the agent. Don't let agents run download-and-execute commands without review. Check packages before installing them. Log what agents read, not only what they run. The web is now part of the software supply chain, and most agents act on it with no check in between.

AI and automation help attackers scan the internet, analyze patches, and build exploits quickly. This means exploitation can begin before a patch is even available.

Modernizing infrastructure is more urgent than ever. Legacy systems like Gen 6 firewalls pose a direct risk to network security. They provide a critical entry point for attackers, offering visibility and access to core systems. Replacing these devices with supported models like Gen 8 is essential to maintaining a secure perimeter.

The time to act is now. Every day an unsupported firewall remains online increases the risk of a breach. Take immediate steps to inventory and retire these devices. If replacement isn't possible, harden the remaining systems with strict access controls and continuous monitoring. One breach can compromise everything.
